# Quick Task 260602-214 — Summary

**Description:** Fix the guest-login / createadmin `plan_id` NOT NULL launch-blocker.
**Date:** 2026-06-02
**Status:** Complete — fix verified end-to-end against real Postgres.

## The bug

`users.plan_id` is `uuid NOT NULL` with no default (migration 019). `GuestLogin` and
`createadmin` called `CreateUser` with `plan_id=''` *before* assigning the system plan,
so Postgres rejected the INSERT (`invalid input syntax for type uuid`). `POST /auth/guest`
(primary free-tier onboarding) and `createadmin` returned 500/failed on any post-019 DB.
The D-29 post-insert UPDATE was dead code. Masked in CI because handler unit tests use
SQLite (loosely typed, accepts `''`).

## Changes

| File | Change |
|------|--------|
| `server/api/internal/handler/auth.go` | `GuestLogin` resolves the system plan via `FindSystemPlanID` and sets `user.PlanID` on the struct literal **before** `CreateUser`; returns a clear 500 when no system plan exists; dead post-insert `UPDATE plan_id` block removed. |
| `server/api/cmd/createadmin/main.go` | `createAdminUser` resolves + sets `PlanID` before `CreateUser`; propagates a wrapped error (non-zero exit) when no system plan exists. |
| `server/api/integration/guest_onboarding_test.go` (new) | `TestGuestOnboardingSetsPlanID` drives `POST /auth/guest` over a real `postgres:16-alpine` container and asserts the minted guest's `plan_id` equals the `is_system` plan. Skips cleanly without Docker. |
| `server/api/internal/handler/auth_test.go`, `cmd/createadmin/main_test.go` | Seeded the `is_system 'free'` plan into the SQLite unit-test fixtures (deviation — required because `FindSystemPlanID` is now a hard precondition; keeps existing happy-path unit tests green). |

**Design constraint honored (D-29):** app-layer assignment only — no schema change, no
nullable column, no DB default. `model/user.go` and `migrations/` untouched.
