## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous internet → /livez, /readyz | unauthenticated health probes (load balancer, uptime monitor) |
| tunnel server → /internal/servers/:id/heartbeat | machine-to-machine, authed by shared secret |
| API → lava.top | outbound reachability probe (cached, never per-request) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-08 | Spoofing | tunnel-heartbeat endpoint | mitigate | X-Internal-Secret compared via crypto/subtle.ConstantTimeCompare (constant-time, no timing oracle); secret required at boot via RequireEnv; NOT IP-based |
| T-07-09 | Info Disclosure | readyz dep status to anonymous callers | mitigate | 503 body carries status WORDS only ("ok"/"down") per dep — never error strings, hostnames, or versions; deps-health detail is the admin-only endpoint (07-09) |
| T-07-10 | DoS | readyz dialing lava on every probe | mitigate | lava reachability cached ≤60s in Redis; any dial wrapped in 2s context timeout; livez does zero I/O |
| T-07-11 | Tampering | heartbeat body load_percent | accept | load_percent is a display int, parameterized into UPDATE; worst case is a wrong dashboard number, no security impact |
| T-07-12 | Elevation | /internal group bypassing admin auth | mitigate | /internal mounts the shared-secret middleware, is NOT under /admin, and is documented as the one non-audited machine endpoint; AppVersion gate skips it explicitly |
</threat_model>
