|----------|-------------|
| admin SPA → /admin/feature-flags, /admin/broadcasts | authenticated admin mutation |
| anonymous/mobile → GET /broadcasts | unauthenticated public read |
| every request → Maintenance middleware | gate that must not lock the operator out |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-27 | DoS / Elevation | maintenance mode locks the operator out | mitigate | Maintenance exempts /admin/*, /auth/admin-login, /livez, /readyz, /internal — the operator can always reach the toggle (Pitfall 5); flag read fails open so a cache+DB outage does not 503 the whole site |
| T-07-28 | DoS | per-request DB read for the flag | mitigate | 10s Redis cache fronts the DB (two-layer, fail-open) — toggles propagate within ~10s without hammering the DB per request |
| T-07-29 | Info Disclosure | broadcast public endpoint leaking internal fields | mitigate | ListBroadcastsPublic returns only {title, body, severity} — no target_tier/updated_by/internal columns |
| T-07-30 | Tampering | broadcast severity / flag value injection | mitigate | severity validated against an enum; flag value is a strict bool; reason trimmed+capped; all stored via parameterized GORM writes |
| T-07-31 | Elevation | flag/broadcast writes without admin | mitigate | all mutating routes on the AdminRequired audited group |
</threat_model>
