## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin SPA → /admin/users/:id/* | authenticated admin bearer-token mutation |
| suspended user → protected routes | a suspended user's still-valid JWT must be rejected |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-13 | Elevation | suspended user keeps access via cached existence | mitigate | suspend calls DeleteUserSessions (refresh path dies) + BustUserCache (5s TTL backstop) + SuspendedRequired does a per-request DB read of suspended_at — stale cache cannot bypass it |
| T-07-14 | DoS | force-disconnect blast radius / double-click | mitigate | IncrRateLimit (atomic Lua) caps ≤1/user/30s → 429; confirm dialog in the UI (07-10) |
| T-07-15 | Repudiation | suspend without recorded justification | mitigate | handler writes CreateAuditEntry with Details["reason"] (Pitfall 4) — the middleware's query-only row is insufficient |
| T-07-16 | Tampering | reason field into audit JSONB | mitigate | reason is trimmed + length-capped and stored as a parameterized JSONB value via GORM (AuditDetails Valuer), never concatenated into SQL |
| T-07-17 | DoS | admin self-lockout via SuspendedRequired | mitigate | admin group does NOT mount SuspendedRequired; admins are not suspendable in v1 |
</threat_model>
