## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator browser → admin-web SPA | bearer-token axios (not cookies) |
| admin-web → admin API | all calls carry the admin JWT via the request interceptor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-40 | Tampering (CSRF) | state-changing admin POSTs from the SPA | accept | admin-web uses bearer-token axios (Authorization header), NOT cookies → not CSRF-exploitable; documented (if cookie auth is ever added, enforce SameSite/Origin — Phase 8) |
| T-07-41 | DoS (self-inflicted) | accidental force-disconnect/drain | mitigate | destructive actions gated behind a confirm Dialog that echoes the target identifier (RESEARCH §9.5); backend throttle (07-04/07-06) is the hard backstop |
| T-07-42 | Elevation | maintenance toggle locking the operator out | mitigate | backend Maintenance middleware exempts admin routes (07-07); the toggle warning copy reminds the operator; admin panel keeps working |
| T-07-43 | Info Disclosure | buyer emails in the webhook log | mitigate | redaction is server-side (07-08); the SPA only renders what the list endpoint returns (already redacted) |
</threat_model>
