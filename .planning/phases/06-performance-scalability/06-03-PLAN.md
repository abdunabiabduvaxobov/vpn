  const serversActiveKey = "cache:servers:active"
  const serversActiveTTL = 60 * time.Second // Fork 4 — matches plansPublicCacheTTL; DEL-on-write makes TTL a safety net

  func GetServersCache(ctx context.Context, client *redis.Client) (string, error) {
      if client == nil { return "", nil }
      val, err := client.Get(ctx, serversActiveKey).Result()
      if err != nil { return "", nil } // redis.Nil OR transient error → fail-open, fall through to DB
      return val, nil
  }
  func SetServersCache(ctx context.Context, client *redis.Client, jsonBody string) error {
      if client == nil { return nil }
      return client.Set(ctx, serversActiveKey, jsonBody, serversActiveTTL).Err()
  }
  func BustServersCache(ctx context.Context, client *redis.Client) error {
      if client == nil { return nil }
      return client.Del(ctx, serversActiveKey).Err()
  }

| API → Redis | cache layer; a Redis outage must degrade to DB (fail-open), never error |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-SRVCACHE-01 | Information Disclosure | non-admin /servers cache path | mitigate | The cached blob is the FULL active-server list, but the plan filter STAYS live in Go for non-admins (intersect with plan's allowed IDs). A non-admin never receives servers outside their plan because the filter runs post-cache, per-request. Admin-bypass preserved. |
| T-06-SRVCACHE-02 | Tampering (stale data) | shared cache vs admin write | mitigate | Synchronous `BustServersCache` before the admin write handler returns + 60s TTL safety net — fresh within one request on write, ≤60s worst case if a DEL fails. |
| T-06-SRVCACHE-03 | DoS / availability | Redis outage on /servers | mitigate | Fail-open: GetServersCache returns "" on outage → handler falls through to DB. /servers never breaks (non-negotiable contract). |
| T-06-SRVCACHE-04 | Tampering | cache key from client input | accept | Key is a server-derived constant `cache:servers:active` — no client input interpolated. No injection surface. |
